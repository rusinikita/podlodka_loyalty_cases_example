# AGENTS.md

Сервис `loyalty`: бэкенд программы лояльности приложения «Шнырь-курьер» (такси и доставка). Промокоды, скидки на следующий заказ, награды за приглашённых друзей. Подробное описание, схемы и зависимости в `README.md`.

## Структура

| Путь | Что там |
|---|---|
| `api/loyalty-api.yaml` | Наш HTTP API: приложение и админка |
| `api/*.yaml` | Спеки соседних сервисов |
| `api/events/` | Схемы входящих событий Kafka |
| `migrations/` | DDL |
| `config/` | `app.yaml` (глобальные лимиты, клиенты), `consumers.yaml`, `workers.yaml` |
| `docs/` | Ранбук дежурного, инструкция поддержки, роли админки |

Код разложен по модулям `promo`, `campaigns`, `discounts`, `referrals`, `admin` плюс каркас: точка входа API, запуск консьюмеров и воркеров, конфиг, клиент БД, HTTP-клиенты внешних сервисов.

## Как работать с кодом

- Код предназначен для чтения. Собирать, запускать и прогонять его не нужно: окружения, зависимостей и тестовой базы здесь нет.
- Документация, описания и переписка на русском; код, идентификаторы, логи и спеки на английском.
