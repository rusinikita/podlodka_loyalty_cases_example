# Админка: роли раздела «Лояльность»

| Действие | `support_l1` | `support_l2` | `loyalty_operator` | `loyalty_admin` |
|---|---|---|---|---|
| Просмотр промокодов, скидок и наград за друзей пользователя | да | да | да | да |
| Просмотр карточки кампании | нет | да | да | да |
| Выдача персональной скидки (лимит в `config/app.yaml`, с номером обращения) | нет | нет | да | да |
| Создание и редактирование кампаний | нет | нет | нет | да |
| Генерация и импорт промокодов | нет | нет | нет | да |

## Кто в какой роли

| Роль | Кому выдана |
|---|---|
| `support_l1` | Первая линия поддержки, 140 человек |
| `support_l2` | Вторая линия поддержки, 12 человек |
| `loyalty_operator` | Разработчики команды лояльности, 6 человек |
| `loyalty_admin` | Тимлид и текущий дежурный команды лояльности |

Роли выдаются по заявке в сервис-деске.

Отдельного аудит-лога нет. Персональная скидка пишется в `user_discounts`: логин оператора в `created_by`, номер обращения в `comment`. У кампаний автор в `campaigns.created_by`.

Доступа к базам и прод-кластеру у поддержки нет. Read-реплика `loyalty-ro` и `kubectl` в неймспейс `loyalty` доступны только разработчикам команды.
