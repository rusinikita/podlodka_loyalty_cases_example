# Промокоды, скидки и награды за друзей: инструкция для поддержки

Раздел базы знаний «Лояльность». Для первой и второй линии.

## Промокоды

**1. Где клиент вводит промокод.** Профиль → «Промокоды» → «Добавить». Промокод из письма или пуша применяется сам по кнопке.

**2. Когда промокод применяется.** К следующему заказу после активации. К уже начатому или завершённому заказу промокод не применяется, даже если клиент активировал его через минуту.

**3. Сколько раз действует один промокод.** Один раз на пользователя, если в условиях акции не сказано иное. Условия видны в админке: Лояльность → Кампании → карточка кампании.

**4. Сколько промокодов можно применить.** Не больше одного на заказ и не больше 3 промокодов в календарный месяц. При превышении клиент видит «Лимит промокодов исчерпан».

**5. Реферальные промокоды (FRIEND…).** Работают только для новых пользователей, до первой завершённой поездки.

**6. Ограничения кампаний.** У кампании могут быть ограничения по городу, времени суток, минимальной сумме заказа, общему числу активаций. Если ограничение не выполнено, клиент видит «Промокод недоступен». Какое именно ограничение сработало, в админке не показывается: уточняйте у дежурного команды лояльности в #loyalty-duty.

**7. Промокод истёк.** Сроки не продлеваем. Исключения только по согласованию с руководителем смены, через дежурного.

## Скидки на следующий заказ

**8. За что даётся.** За оплаченный заказ по акции, например с товарами из акционного списка. Скидка приходит в течение нескольких минут после оплаты, клиент получает пуш. Не даётся за корпоративные заказы (оплата по счёту компании) и за отменённые заказы.

**9. Как действует.** Скидка применяется к следующему заказу автоматически и действует 30 дней. Скидки не суммируются: к заказу применяется одна.

## Награды за друзей

**10. Как получить.** Клиент делится ссылкой из раздела «Пригласи друга». Когда друг регистрируется по ссылке, пригласившему начисляется 500 ₽ на карту. Для выплаты в профиле должна быть привязана и подтверждена карта. Друг должен открыть ссылку и зарегистрироваться с одного и того же телефона, иначе приглашение не привязывается.

**11. Награда не пришла или пришла не на ту карту.** Выплата уходит на карту, привязанную в момент выплаты, банк зачисляет до 3 рабочих дней. Повторно не выплачиваем. Если прошло больше 3 рабочих дней, напишите в #loyalty-duty id пригласившего и приглашённого.

## Компенсации

**12. Компенсации скидкой.** Размер компенсации определяет оператор по таблице компенсаций. Выдаёт дежурный команды лояльности: напишите в #loyalty-duty id пользователя, размер скидки, причину и номер обращения.
